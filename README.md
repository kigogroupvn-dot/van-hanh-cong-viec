# Vận hành công việc · Khối Marketing Kigo Group

Web nội bộ tổng hợp kế hoạch, phân công, tiến độ tuần và doanh số.

- `index.html`: giao diện web
- `config.js`: file duy nhất cần sửa — link Google Sheets dữ liệu và link cầu nối doanh số
- Dữ liệu nằm trên Google Sheets "Vận hành công việc". Không đổi tên tab hoặc tên cột khi chưa báo người dựng web.
- `fonts/`: font theo bộ nhận diện (đã có bản quyền sử dụng)
